# 世界通史时空图谱 · World History Atlas

按时间顺序动态呈现 **公元前 3000 年 — 公元 2025 年** 世界历史疆域变迁、重大历史转折事件与著名历史人物的交互式通史学习地图。

- **在线访问（Cloudflare Pages）**：https://world-history-atlas-ckn.pages.dev/
- **适配终端**：桌面端 / 平板 / 手机移动端响应式体验

---

## 核心功能与内容结构

- **八大加权时代与 49 期历史疆域截面**：覆盖从大河青铜文明、轴心时代与古典帝国、帝国重构、草原与商网、大航海与白银全球化、双元革命、两次大战与冷战到当代多极数字时代；点击地图任意政权区域可查看中英文政权名称及对应年代版图。
- **146 个结构化历史大事卡片**：统一按照 **地缘与自然条件 / 政治博弈与制度 / 经济与贸易逻辑 / 文化与思想影响 / 长期历史后果 / 史学争鸣 / 因果前后链** 精炼拆解，支持点击上下游因果节点与地图发光弧线跨时代追踪。
- **87 位著名历史人物档案与同时代人物交汇**：分为「帝王与政治家」「思想家与宗师」「科学家与发明家」「改革家与航海家」四大类方印徽章，支持事件 ↔ 人物双向跳转，并基于生卒年自动关联全球跨文明同时代人物。
- **四维筛选、18 条历史商路与 20 期同代横切**：支持按政治、经济、文化、科技筛选，叠加丝绸之路、大帆船白银航线等历史通道，或在「同代横切」面板横向对比同时期亚非欧美六大区域发展形态。
- **5 条专题导览故事线与多模式地图**：支持 2D 平面地图 / 3D 地球仪切换、羊皮纸 / 暗夜黑双主题，内置掌握标记、收藏、个人学习笔记及 JSON 一键导入/导出备份。

## 本地开发与构建

```bash
npm install
npm run data:validate   # 校验时代、事件、人物、商路、专题导览与同代横切数据完整性
npm run dev             # 启动本地开发服务器
npm run build           # 复制 MapLibre Worker、执行 TypeScript 检查并打包 dist/
```
